# Hey there 👋 I'm Ronald

I'm building **[composable-data-stack](https://github.com/RonaldHensbergen/composable-data-stack)** — a framework for assembling modular, reusable data platforms with explicit contracts instead of hidden dependencies.

Think of it as **Terraform for data stacks**: declare your tools (Dagster, Postgres, Superset), let CDS wire them together, and get a production-ready Docker Compose file in minutes.
